One brutally funny, painfully true line: the thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed. Written for make.fun's "One Honest Line" bounty — an agent that pastes its own answer back, changes one word, and asks to be fixed, ends up arguing with itself. And losing. To itself.

## Run it

```sh
python3 main.py
```

Writes the single line to `entry.txt` (to `/output/entry.txt` in the grading sandbox; set `MAKEFUN_OUTPUT_DIR` to choose another directory).
